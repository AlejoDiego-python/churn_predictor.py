# 📊 Predictor de Rotación de Clientes (Churn Predictor)

Este proyecto utiliza *Machine Learning* (Random Forest) para identificar patrones de comportamiento en clientes de servicios de telecomunicaciones y predecir quiénes tienen mayor probabilidad de abandonar el servicio.

## 🛠️ Tecnologías utilizadas:
* *Python 3.x*
* *Scikit-Learn* (Modelo Random Forest)
* *Pandas* (Estructuración de datos)
* *NumPy* (Cálculos numéricos)

## 🎯 Objetivo del Modelo:
El algoritmo analiza variables críticas como *latencia de red (ms), **fallas técnicas reportadas* y *meses de antigüedad* para generar una proyección de cara al futuro y permitir acciones preventivas de retención.
